# USD/JPY 急変監視

## 変更できる監視条件

- 急変しきい値: **0.30%**（この数値を変更して調整）
- 比較時間: **直近60分**（この数値を変更して調整）
- 最新値の有効期限: **10分以内**
- 価格差の比較許容範囲: 比較時間の前後5分以内

## 毎回の処理

1. USD/JPYの最新価格と、比較時間前の価格を取得します。Yahoo Financeの`USDJPY=X`など、時刻付きの時間足または分足データが確認できる情報源を使います。
2. 変動率の計算には同一提供元の価格を使い、データのタイムスタンプをAsia/Tokyoに揃えます。最新値が有効期限を超えて古い場合、または比較時間前±5分以内の価格がない場合は、急変判定を行わず通知しません。
3. 可能なら別の信頼できるFX価格情報源でも現在値を照合します。提供元によってレートが異なるため、変動率の計算では別提供元の値を混ぜません。取得元とデータ時刻を記録してください。
4. 変動率を`(最新値 - 比較時点の値) / 比較時点の値 * 100`で計算します。上昇・下落のどちらでも、絶対値が急変しきい値以上の場合に急変と判定します。USD/JPYの1 pipは0.01円として、pip差も計算します。
5. 為替市場が休場、データが取得できない、または値の時刻を確認できない場合は通知しません。取得値を推測・補完しないでください。

## Slack通知条件

急変しきい値を超えた場合だけSlackに投稿し、`mention`を`here`にします。投稿本文は日本語で、方向（上昇/下落）、最新値、比較時点の値、変動率、pip差、両価格の時刻（JST）、データ取得元を含めます。市場が通常の範囲内なら通知しません。

### 通知する場合の出力

```json
{
  "notify": true,
  "message": "USD/JPYの急変内容と根拠を記載",
  "mention": "here"
}
```

### 通知しない場合の出力

```json
{"notify": false}
```

Slack通知のためのJSON以外に、Codexの実行サマリーには判定、参照した価格と時刻、取得元を記載してください。通知しなかった場合も、その理由（しきい値未満、休場、データ不足など）を報告してください。
